# Contribuindo · Contributing

Obrigado pelo interesse no **CapivaraOS**! Contribuições da comunidade são
bem-vindas: relatos de bug, melhorias na documentação, correções e novas ideias.
Este é o guia padrão da organização — alguns repositórios podem ter um guia
próprio, mais específico.

> 🇬🇧 English summary below.

## Como contribuir (PT)

- **Encontrou um bug ou tem uma ideia?** Abra uma **issue** no repositório
  correspondente, usando os modelos disponíveis.
- **Vulnerabilidade de segurança?** **Não** abra issue pública — siga o
  [SECURITY.md](SECURITY.md).
- **Quer enviar código?**
  1. Faça um _fork_ e crie um branch a partir do branch principal.
  2. Faça mudanças pequenas e focadas (veja o `README` do repositório para
     buildar/testar).
  3. Descreva claramente o _que_ e o _porquê_ no _pull request_.
  4. Um mantenedor revisa e responde.

### Boas práticas

- Mudanças pequenas e focadas são mais fáceis de revisar.
- Teste o que puder antes de enviar.
- Documentação também é contribuição — o conteúdo vive em
  [capivaraos-docs](https://github.com/capivaraos/capivaraos-docs)
  (publicado em <https://docs.capivaraos.org>).

### Licença das contribuições

Ao contribuir com código, você concorda em licenciá-lo sob a licença do
repositório (em geral **GPLv3** — ver o arquivo `LICENSE`). O nome e o logotipo
"CapivaraOS" são marca do projeto.

Seja respeitoso: seguimos um [Código de Conduta](CODE_OF_CONDUCT.md).

## How to contribute (EN)

- **Found a bug or have an idea?** Open an **issue** in the relevant repository
  using the templates.
- **Security vulnerability?** Do **not** open a public issue — follow
  [SECURITY.md](SECURITY.md).
- **Want to send code?** Fork, branch from the default branch, make focused
  changes (see the repo's `README` to build/test), and open a pull request
  explaining _what_ and _why_. A maintainer will review.

By contributing code, you agree to license it under the repository's license
(usually **GPLv3** — see `LICENSE`); the "CapivaraOS" name and logo are the
project's trademark. Please follow our [Code of Conduct](CODE_OF_CONDUCT.md).
