# Suporte · Support

> 🇬🇧 English below.

## Precisa de ajuda? (PT)

- 📚 **Documentação:** <https://docs.capivaraos.org> — guias de instalação, uso,
  segurança e administração.
- 🌐 **Site:** <https://capivaraos.org>
- 🐛 **Bug ou dúvida técnica:** abra uma **issue** no repositório correspondente,
  usando os modelos disponíveis.
- 🔒 **Falha de segurança:** **não** abra issue pública — veja o
  [SECURITY.md](SECURITY.md).

O CapivaraOS é um projeto comunitário; respondemos em regime de **melhor
esforço**. Ao relatar um problema, inclua a versão afetada e passos para
reproduzir — ajuda muito.

---

## Need help? (EN)

- 📚 **Documentation:** <https://docs.capivaraos.org>
- 🌐 **Website:** <https://capivaraos.org>
- 🐛 **Bug or technical question:** open an **issue** in the relevant repository
  using the templates.
- 🔒 **Security flaw:** do **not** open a public issue — see
  [SECURITY.md](SECURITY.md).

CapivaraOS is a community project; we respond on a **best-effort** basis. When
reporting an issue, include the affected version and steps to reproduce.
